***Evaluation Source code:
File 1: gen_dataset_and_queries: Generating dataset and queries from UIT-ViQuAD2.0.
	*Update: 'answers' dictionary column is converted to 'answer' string column in queries, just take 'text', no 'answer_start'
There are 04 versions:
1. 'in_dataset': All queries are in dataset.
	For each context, question, randomly pick N samples from dataset_filtered_full after filering no answer sample.
	*Dataset: dataset_filtered_full

2. 'out_dataset': All queries are NOT in dataset.
	For each context, question, randomly pick N samples from dataset_filtered_full after filering no answer sample.
	dataset_filtered_full is dropped these N samples to dataset_filtered_dropped.
	*Dataset: dataset_filtered_dropped

3. 'similar_dataset_within_context': All queries are SIMILAR to queries in dataset being generated by questions WITHIN context.
	For each context, question, randomly pick N samples from dataset_filtered_full after filering no answer sample.
	Call ChatGPT to generate N similar questions to N questions of picked samples with prompts having context of the sample.

4. 'similar_dataset_without_context': All queries are SIMILAR to queries in dataset being generated by questions WITHOUT context.
	For each context, question, randomly pick N samples from dataset_filtered_full after filering no answer sample.
	Call ChatGPT to generate N similar questions to N questions of picked samples with prompts NOT having context of the sample.

File 2: gen_evaluations: Generating evaluations and evaluation summaries with many middle files from dataset and queries.
For each number of samples and version, we edit max_samples and version and Run All to generate all of files.
0. Load libraries and models and denfine functions
	input files: dataset.xlsx + queries.xlsx
1. Load dataset and queries
	*Update: 	After first embedding and indexing dataset, these embeddings and index are saved into files ('.pt' and '.bin').
			If the dataset is not changed, just load embeddings and index from files, no embed again.
2. Gen retrieved contexts
	*Update: 	If query is in the dataset, look it up and use the looked context in dataset as retrieved context.
			else call retrieve_top_k()
3. Gen conversation
4. Gen answer (Call Chat GPT)
5. Gen response
6. Generate evaluation (RAGAs)
	output file: evaluations.xlsx
	*Update: Call create_summary() to record True and False evaluation summaries.
